# Smart Face Recognition Attendance System 🎓

A Python-based desktop application that uses AI to identify students via webcam and automatically logs their attendance to a daily CSV file.

## Features ✨
- **Real-time Face Recognition:** Uses DeepFace (VGG-Face) and RetinaFace for high accuracy.
- **Interactive GUI:** Built with Tkinter for easy use (Start/Stop camera, View CSV).
- **Live Registration:** Register new students directly from the app (takes a 3-second timed photo).
- **Automated Logging:** Generates `attendance_YYYY-MM-DD.csv` files automatically and prevents duplicate entries.

## Prerequisites 🛠️
- Python 3.10+
- A working webcam
